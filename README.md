# Cairo University Management System

A university management system built using PHP, MySQL, HTML, CSS, Bootstrap and XAMPP.

## Features

- Add students
- View students
- Edit students
- Delete students
- Add doctors
- View doctors
- Edit doctors
- Delete doctors
- Add departments
- View departments
- Edit departments
- Delete departments
- Add courses
- View courses
- Edit courses
- Delete courses

## Technologies

- PHP
- MySQL
- HTML
- CSS
- Bootstrap
- XAMPP

## Database

The database structure and sample data are available in:

`database.sql`

## How to Run

1. Install XAMPP.
2. Start Apache and MySQL.
3. Place the project inside the XAMPP `htdocs` folder.
4. Open phpMyAdmin.
5. Create a database named `nti`.
6. Import `database.sql`.
7. Open the project through:

`http://localhost/Projects/cairo-university/`
